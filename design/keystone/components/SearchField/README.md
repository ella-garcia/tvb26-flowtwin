# SearchField

The toolbar search box, right-aligned at the end of the toolbar.

**Provide:** optional `placeholder` (default "Search"), `label` when the placeholder isn't descriptive, `value`/`onChange` or `defaultValue`, `width` (≈ 390px on desktop).

- Its border is `border-control` (≥3:1) because the edge is the only cue; focus shows the `focus-ring`.
- Input text is 16px so mobile browsers don't zoom.
