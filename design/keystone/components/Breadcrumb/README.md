# Breadcrumb

The trail at the top-left of the main area: a module icon, then crumbs separated by chevrons; the current page sits on `surface-selected`.

**Provide:** `items` (`{label, href}`; the last one is the current page), optional `icon` (the rail module's icon; `false` for none).

- Two levels is typical: module › page ("Persiapan › Penyusunan Feasibility Study").
- The page title below repeats the last crumb in `title`.
